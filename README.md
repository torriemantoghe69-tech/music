# 声屿 Music

一个纯前端、本地优先的音乐播放器。无需安装依赖，使用现代浏览器打开 `index.html` 即可运行，也可部署到 GitHub Pages。

## 功能

- 多选导入本地音频、拖放导入、文件夹导入
- 歌曲列表、搜索、名称/艺术家/最近添加排序
- 播放、暂停、上一首、下一首、随机播放、单曲循环
- 进度拖动、音量控制、收藏、最近播放
- 适配桌面和手机屏幕
- 不会上传音乐文件；文件仅在当前浏览器会话中读取

## 格式说明

播放器使用浏览器原生音频解码能力。常见的 MP3、WAV、AAC/M4A、OGG、Opus、FLAC 等格式会根据浏览器和系统编解码器支持情况播放。WMA、APE、ALAC 等格式并非所有浏览器都支持；文件能被导入不代表当前浏览器一定能解码。所谓“全格式”播放需要额外集成解码器或桌面端音频引擎，不能仅靠网页标准保证。

## 运行

直接打开 `index.html`。推荐使用最新版 Chrome、Edge 或 Firefox。

## 隐私

本项目不包含上传接口、账号系统或云端音乐存储。关闭或刷新页面后，浏览器本地文件对象不会自动恢复，需要重新选择音乐文件。
